# Ce que morfSystem n'est pas

Comprendre morfSystem consiste autant à comprendre ce qu'il refuse qu'à comprendre ce qu'il propose.

L'écosystème fait des choix.

Ces choix impliquent également des renoncements.

Ils sont assumés.

Ils participent à son identité.

---

# morfSystem n'est pas un framework

Un framework impose généralement une manière de développer.

Il fournit une base commune.

Une architecture.

Des bibliothèques.

Des conventions.

morfSystem n'impose rien de tout cela.

Il définit des principes.

Les implémentations restent libres.

---

# morfSystem n'est pas une suite logicielle

Les composants peuvent fonctionner ensemble.

Ils n'ont pas été conçus pour être installés obligatoirement ensemble.

Chaque projet conserve sa propre utilité.

L'utilisateur compose son propre environnement.

---

# morfSystem n'est pas un système d'exploitation

L'écosystème fonctionne sur plusieurs plateformes.

Linux.

Windows.

ESP32.

Raspberry Pi.

Il ne cherche jamais à masquer leurs différences.

Il les respecte.

---

# morfSystem n'est pas cloud first

Le fonctionnement normal s'effectue sur le réseau local.

Aucune infrastructure distante n'est nécessaire.

Les accès externes sont possibles.

Ils restent des extensions.

Le cœur de l'écosystème demeure local.

---

# morfSystem n'est pas un orchestrateur

Les composants se découvrent.

Ils collaborent.

Ils ne sont jamais pilotés par un composant central.

Il n'existe pas de chef d'orchestre.

Seulement des services autonomes.

---

# morfSystem n'est pas une plateforme IoT

Certains composants utilisent des objets connectés.

D'autres non.

L'objectif n'est pas de construire une plateforme IoT.

L'objectif est de construire un écosystème logiciel cohérent.

Les ESP32 constituent simplement une des plateformes supportées.

---

# morfSystem n'est pas une collection d'API

Les API sont des moyens.

Jamais une finalité.

Chaque API existe parce qu'elle répond à une responsabilité.

Pas pour être exhaustive.

Pas pour être tendance.

---

# morfSystem n'est pas un laboratoire technologique

Les nouvelles technologies sont évaluées.

Elles ne sont jamais adoptées uniquement parce qu'elles sont nouvelles.

La stabilité.

La simplicité.

La lisibilité.

Restent prioritaires.

---

# morfSystem ne cherche pas la performance absolue

Une architecture extrêmement rapide mais difficile à maintenir n'est pas un objectif.

L'écosystème recherche un équilibre.

Une solution suffisamment performante.

Compréhensible.

Stable.

Maintenable.

---

# morfSystem ne cherche pas à tout résoudre

Chaque projet possède des limites.

Ces limites sont volontaires.

Lorsqu'un besoin dépasse une responsabilité existante, un nouveau composant peut apparaître.

Pas une accumulation de fonctionnalités.

---

# morfSystem ne cherche pas à remplacer les outils existants

De nombreux logiciels accomplissent déjà parfaitement certaines tâches.

morfSystem ne cherche pas à les concurrencer.

Il cherche à résoudre des besoins spécifiques avec une architecture cohérente.

Lorsqu'un outil externe répond déjà correctement à un besoin, il peut être utilisé.

Il n'est pas nécessaire de le réécrire.

---

# morfSystem n'est pas terminé

L'écosystème évolue.

Il continuera d'évoluer.

Mais son évolution repose sur des principes stables.

L'objectif n'est pas de figer les logiciels.

L'objectif est de préserver leur cohérence.

Cette distinction est essentielle.

---

# Ce que morfSystem cherche réellement

Construire des logiciels simples.

Autonomes.

Compréhensibles.

Libres.

Capables de collaborer sans perdre leur indépendance.

Tout le reste découle naturellement de cet objectif.
